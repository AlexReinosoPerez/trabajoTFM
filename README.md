# Van Gogh Authenticator – TFM

Este proyecto tiene como objetivo desarrollar un sistema basado en deep learning para determinar si una obra atribuida a Vincent van Gogh es auténtica o falsa. Incluye un modelo de clasificación binaria entrenado con PyTorch, una interfaz de inferencia con Streamlit y trazabilidad completa de experimentos mediante MLflow.
